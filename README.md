# SparePartsPro — Releases

This repository only publishes **SparePartsPro release notes and installers**.
It contains no source code and no shop data.

SparePartsPro checks this repository for new versions and shows the release notes
inside the app (**Updates → Release notes**). Each release contains:

- `SparePartsPro-Setup-x.y.z.exe` — the Windows installer
- `SparePartsPro-Setup-x.y.z.exe.sha256` — checksum the app verifies before installing
